## Generation Workflow

1. Generate at 1024x1024 minimum using NanoBanna 2 or equivalent
2. Upscale to 2048x2048 with Magnific AI for detail retention
3. Remove background with Remove.bg or Photopea for transparent PNG
4. Downscale to target size (256x256 for sprites, 1920x1080 for rooms)
5. Validate against this document's color reference and style keywords
6. Run through CONSISTENCY_GATE.md checklist before committing to asset pipeline
