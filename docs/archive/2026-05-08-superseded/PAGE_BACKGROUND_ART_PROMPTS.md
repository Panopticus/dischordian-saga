## PRODUCTION NOTES

### Style Guide
- **Resolution:** 1920x1080 JPG
- **Aesthetic:** Dark sci-fi, generation ship interior
- **Palette:** Dark backgrounds (#0a0a1a to #1c1917), accent lighting only
- **Opacity in-game:** 0.12-0.18 (backgrounds are subtle, not dominant)
- **Depth map:** Generate Immersity AI disparity maps for parallax effect

### Naming Convention
```
{CODE}_{NAME}.jpg          → color image
{CODE}_{NAME}_disparity.png → depth map for parallax
```

### CDN Upload Path
```
Cloudinary: /v{timestamp}/{CODE}_{NAME}_{hash}.jpg
S3: page-backgrounds/{code}/{name}.jpg
```

### Integration Pattern
```tsx
// In the page component:
import LivingBackground from "@/components/LivingBackground";
// or for parallax:
import ParallaxDepthBackground from "@/components/ParallaxDepthBackground";

// In the return:
<LivingBackground src={imageUrl} accent={accentColor} opacity={0.15} />
```
