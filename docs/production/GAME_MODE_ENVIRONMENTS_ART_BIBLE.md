# GAME MODE ENVIRONMENTS — ART PROMPT BIBLE
## Every Missing Background, Arena, and Scene for Playable Game Modes
### docs/production/GAME_MODE_ENVIRONMENTS_ART_BIBLE.md

**Style Direction:** All environments exist aboard Inception Ark 1047 or in connected locations (New Babylon, the Matrix of Dreams, deep space). Dark sci-fi aesthetic with Void Energy design language — deep space blacks, holographic overlays, neon accent lighting. Each game mode has a distinct mood but shares the foundational visual language.

**Standard Suffix (append to all prompts):** `Dark sci-fi interior, holographic displays, neon accent lighting, Inception Ark aesthetic, cinematic composition, high detail, 4K quality.`
