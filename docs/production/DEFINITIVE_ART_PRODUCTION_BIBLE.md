## GLOBAL STYLE GUIDE

### Aesthetic Pillars
- **Dark sci-fi** with bio-mechanical horror undertones
- **Dramatic rim lighting**, volumetric fog, god rays
- Color palette: deep blacks, dark purples, toxic greens, corrupted
  reds, cold cyans, amber-orange (Hierarchy / Nilmorg accents)
- **No text** in generated images (overlaid in code at runtime)
- Transparent backgrounds for all sprites (PNG with alpha)
- Dark backgrounds, never pure white
- Holographic elements: scanlines, slight transparency, edge glow
- Corruption: VHS tracking, glitch artifacts, text distortion
- Scale: make the player feel small inside a vast, dangerous ship
- Emotion: every portrait should tell a story without words

### Recommended Tools (Pipeline)
1. **NanoBanna 2** — character art, creatures, environments
2. **Magnific AI** — upscaling generated images to production res
3. **Remove.bg / Photopea** — background removal for sprites
4. **Kling AI / Runway / Veo 3.1** — video generation (cinematics)
5. **Suno AI / Udio** — music generation
6. **ElevenLabs** — voice-over generation
7. **Immersity AI** — depth maps for parallax rooms

### Resolution Pipeline
1. Generate at highest available resolution (1024–2048+ short side)
2. Upscale via Magnific to 4x where needed
3. Background removal for sprites
4. Export PNG with alpha
5. Downscale to target with bicubic resampling
6. Verify on dark background

### File Naming Convention
```
{game}_{category}_{name}_{size}.{ext}
```

- `cades_char_iron-lion-imprint_1024x1536.png`
- `dmc_env_the-trench_1920x1080.jpg`
- `loredex_concept_goggles_1024x1024.png`

## CONSISTENCY GATE CHECKLIST

Every generated asset must pass this checklist before entering the
S3 CDN. The checklist lives in `CONSISTENCY_GATE.md` but is
summarized here.

1. **Character consistency** — face matches the last 3 approved
   anchors for that character
2. **Palette consistency** — color uses the canonical hex for that
   character/location
3. **Outfit consistency** — no drift from approved outfit anchors
4. **Style tokens present** — dark sci-fi, rim lighting, volumetric
   fog
5. **"Never depict" rules respected:**
   - Never depict Agent Zero as male
   - Never depict The Warlord as male
   - Never depict The Enigma with non-Kenyan features
   - Never depict Nilmorg with actual hands
   - Never depict Iron Lion without the golden lion crest
   - Never depict Thoughtborn as hostile/armed
6. **No text** in the image (text is overlaid in code)
7. **Transparent background** for sprites
8. **Anchor pose variety** — pose must differ from the 3 most recent
   approved assets for that character
