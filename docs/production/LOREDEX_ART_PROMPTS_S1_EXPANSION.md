# LOREDEX ART PROMPTS — Season 1 Expansion
## Per-Entry NanoBanna 2 Prompts for the 29 New Loredex Entries

> This file provides a **single NanoBanna 2 generation prompt** for
> every new Loredex entry card image. Each entry card image slot
> in `loredex-data.json` has an `image` URL that maps to a file in
> the S3 loredex bucket. Generate the prompt listed here, upscale
> via Magnific, and upload to the S3 path listed under the entry.
>
> **S3 root:** `https://dgrsart.s3.us-east-2.amazonaws.com/loredex/`
>
> All images should be 1024×1024 or 1024×1536, dark sci-fi
> aesthetic, transparent or painterly background. See
> `DEFINITIVE_ART_PRODUCTION_BIBLE.md` for the global style guide.

## 6. GENERATION CHECKLIST

Before running any of these prompts:

1. **Global NanoBanna 2 parameters:**
   - Model: NanoBanna 2 (or flux-dev fallback)
   - Guidance: 7.5
   - Steps: 40
   - Seed: random, but record in filename (`_seed{N}.png`)
   - Upscale: Magnific 4x on final approved generation

2. **Character color match:**
   Verify the hex color in the prompt matches the canonical color
   for that character (see `DEFINITIVE_ART_PRODUCTION_BIBLE.md`
   Master Color Reference).

3. **Consistency anchors:**
   For recurring characters (Iron Lion, Elara, Human), generate
   with the last 3 approved portrait anchors as reference images.
   See `CONSISTENCY_GATE.md`.

4. **Forbidden elements:**
   - No text in image output (text overlays are added in code)
   - No pure-white backgrounds (dark sci-fi aesthetic only)
   - No violation of the "Never depict" rules in the Definitive
     Art Production Bible

5. **Upload path:**
   After approval, upload to
   `https://dgrsart.s3.us-east-2.amazonaws.com/loredex/{entry_id}.png`

6. **Verify in-app:**
   Each loredex entry already has its `image` field pointing at
   `dgrsart.s3.us-east-2.amazonaws.com/loredex/{entry_id}.png`,
   so no code changes are required once the image is uploaded.
