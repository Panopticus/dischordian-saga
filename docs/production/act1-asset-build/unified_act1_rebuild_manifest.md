# Unified Act 1 Rebuild Manifest

This rebuild merges the existing **Act 1 AAA asset set** with the uploaded **refreshed art bundle** and remakes the combined collection as one coherent visual field. The new direction must preserve intentional sub-style differences while keeping a single premium production language across all deliverables.

| Directive | Production Interpretation |
|---|---|
| Unified field | All images should feel like they belong to the same game, with shared rendering quality, lighting discipline, edge treatment, texture behavior, and cinematic color logic. |
| Celebration | Keep the **evil Disney** emotional register, but render the characters as **creepy child versions** grounded in canon reference traits rather than generic mascots. |
| Mechronis | Keep the **cyber-steampunk Harry Potter** identity, with academy uniforms, brass-tech detail, elite-school architecture, and dramatic practical lighting. |
| Card art | Make it more overtly **artistic, iconic, and premium**, while still matching the same universe and color discipline. |
| Canon images | The uploaded named character PNG files are the **primary character-design references** and should determine face structure, hair logic, silhouette, costume cues, and material identity. |
| Zip bundle | The refreshed zip images define the preferred **runtime mood and look language** and should be used as the secondary environment and staging references. |

The shared rendering language for the remake is as follows. Every image should read as **AAA narrative-card-game key art** with cinematic realism, stylized painterly control, premium texture separation, deep atmospheric perspective, deliberate color scripting, and clean subject readability. Portraits should feel like prestige game character key art rather than photographs. Environments should feel stageable and playable, with clear focal planes and legible gameplay space. Card art should feel more symbolic and visually elevated than the portraits, but it must still belong to the same universe.

| Visual Layer | Unified Rule |
|---|---|
| Lighting | Strong cinematic key light, disciplined rim separation, practical-source motivation, rich shadow detail, no muddy midtones. |
| Surface treatment | High-end painterly realism with visible material intent: cloth, brass, steel, glass, skin, smoke, parchment, and weathered wood should all separate clearly. |
| Color logic | Shared premium palette discipline across the project, with localized variations per faction or era instead of random color drift. |
| Composition | Strong hero focus, foreground-to-background depth, readable silhouette, and UI-safe negative space where applicable. |
| Finish | Slight stylization for game-art cohesion, but no cheap concept-art roughness and no mushy AI texture confusion. |

## Battlefield Rebuild Rules

Battlefields must look less like neutral backgrounds and more like **playable prestige key environments**. Each one needs a strong focal plane for gameplay and enough atmosphere to feel like a real place in the same unified game.

| Battlefield Asset | Rebuild Direction |
|---|---|
| Celebration spaces | More sinister fairy-park atmosphere, child-world innocence corrupted, premium whimsical menace. |
| Mechronis spaces | Stronger cyber-steampunk academy identity with brass, stone, stained light, and institutional grandeur. |
| Nexon and Vortex spaces | More dramatic warfront skies, impossible energy, and heavier environmental storytelling. |
| Zenon spaces | More militant, improvised, survivalist, and materially precise. |
| New Babylon and Authority spaces | More ceremonial, judicial, cathedral-state grandeur with polished dark surfaces and hard spotlight logic. |
| Ark Archives | Keep continuity with prior Archives material, but bring the same painterly AAA finish and unified color design. |

## Card-Art Rebuild Rules

The card art should be remade so that it looks **more artistic and cool** than the current set, while remaining canon-coherent. These should feel closer to premium TCG splash art: stronger symbolism, more exaggerated light design, cleaner iconic shapes, and more graphic readability at card size. The illustrations can be more poetic and stylized than the portraits, but should still share the same material discipline and universe logic.

| Card-Art Layer | Rebuild Direction |
|---|---|
| Celebration cards | Storybook menace, nostalgic glow, symbolic objects with elevated composition. |
| Academy cards | Brass-academic mystique, ritualized objects, prestige-school emotional intensity. |
| War cards | Harder silhouettes, stronger contrast, iconic objects with emotional violence. |
| Tribunal cards | Ritual object focus, sacred-judicial geometry, mythic gravitas. |
| Procedural memorial card | Elegant memorial frame, solemn luminous treatment, premium collectible readability. |

## Output Strategy

The rebuilt package should include the full remade collection under a new unified delivery folder so it does not overwrite the earlier version until final packaging is complete. The final archive should contain the remade portraits, remade battlefields, remade card art, and the merged refreshed-bundle runtime images if they are rebuilt as part of the same unified set.
