## PRODUCTION NOTES

**Post-processing pipeline:** NanoBanna 2 → Magnific AI (upscale) → Remove.bg (PNG transparency for portraits)

**Consistency anchors:**
- All classroom JPGs should match the tonal range of `arena-mechronis.jpg` (dark indigo base, ~18% opacity when used as page backgrounds)
- All Mascoteer PNGs should feel like they belong in the same Celebration — same lighting temperature, same child-proportions, same "wrong brightness" quality
- All Opponent PNGs should feel like a yearbook from a school that trains killers — uniform baseline, individual rebellion in the details

**Color anchors per character set:**
| Set | Primary | Secondary | Forbidden |
|-----|---------|-----------|-----------|
| Classrooms | Professor's guild accent | Dark obsidian base | Bright white (except Aoki) |
| Mascoteers | MASCOTEER_ACCENT from ApprenticePage.tsx | Warm child-tones | Military colors |
| Opponents | Steel/academy grey | Character's faction hint | Celebration warmth |
