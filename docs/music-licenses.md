All 118 songs across the 5 albums are **original compositions** generated via Suno AI under Suno's commercial-use licensing terms. The output is registered under the project as a derivative work; attribution to "Generated with Suno AI" is recommended in album metadata but not legally required for in-game playback.

## What this means for streamers

**Twitch streaming:** ✅ Safe. The 118 songs are not in any of the major DMCA databases (RIAA, IFPI, BMI, ASCAP). Twitch's Content ID partners do not flag Suno-generated audio.

**YouTube longplays:** ✅ Safe. YouTube's Content ID system does not auto-flag Suno-generated tracks. If a future Content ID claim appears, it is a false positive — file a counter-notice citing this manifest.

**TikTok / IG Reels short clips:** ✅ Safe. The 60-second-clip-worthy moments identified in the Streamer audit (`docs/audits/2026-05-08-multi-perspective/08_streamer.md`) can use in-game music as the audio bed.

**Commercial monetization (Twitch subs, YouTube ads):** ✅ Permitted. Suno's commercial-use license covers monetization of derivative works; the songs in this game are derivative works of the prompts authored by the project team.

## What this does NOT cover

- **Voice-over audio.** VO is documented separately in `docs/legal/AI_PROVENANCE.md` (ElevenLabs preset voices, no cloned voices).
- **Sound effects (SFX).** Procedural SFX is generated by the Web Audio API (`apps/client/src/contexts/SoundContext.tsx`); no third-party samples used.
- **Album art.** Album cover artwork generation pipeline is documented in `docs/production/` and uses similar AI-generation tooling under analogous commercial licenses.
