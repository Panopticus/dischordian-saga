## The structural innovations

### 1. Trust bands (3-band, 4-band, 5-band variants)

**Source bibles**: Locke (3-band: Hostile / Neutral / Trusted), Seer (3-band: Wary / Witnessed-or-Present / Inheriting + Inheriting-Act-7-only), Companion (4-band channel-gated: Wary / Witnessed / Present / Inheriting), Oracle (4-band act-progression-gated: Wary / Witnessed / Present / Inheriting), Hierophant (5-band: Hostile / Wary / Witnessed / Present / Inheriting + sacrifice-axis-inversion).

**The structural innovation**: trust-bands canonically gate canonical-line-availability per canonical-bond-meter or canonical-narrative-progression. Each bible canonically extends the canonical-baseline pattern with canonical-specific-extensions (Companion's *capability-gating* not just *content-gating*; Hierophant's *sacrifice-axis-inversion*; Oracle's *act-progression-gating not bond-gating*; Seer's *Inheriting-Act-7-only-and-single-line-only*).

**Stage 2 authoring guidance**: per canonical-bible's canonical §3.3, identify canonical-band; canonical-line canonically operates *only* at canonical-permitted band. Selector enforces.

**Source bible**: Nilmorg.

**The structural innovation**: canonical Nilmorg canonically operates in canonical *two-distinct-registers* per canonical-context — canonical *broadcast* (canonical institutional register) for canonical-public-DMC-content; canonical *one-on-one* (canonical-warmth-flattened register) for canonical-direct-player-engagement.

**Stage 2 authoring guidance**: canonical Nilmorg-line canonically *flags canonical-context*; canonical-register canonically *follows canonical-flag*. Writers must NOT canonically mix registers within a single canonical-line.

### 3. Non-verbal expression (channels-as-grammar)

**The structural innovation**: canonical-expression canonically operates through canonical-multi-channel canonical-grammar. **Stage 2 authoring guidance**: canonical-expression canonically *defaults to three-channel-minimum* per canonical-Eidolon §2 framework. Channels canonically *layer*, not canonical-multiplex.
