# Human Portrait Set Notes

The Human portrait set preserves a consistent centered clone-built identity across the three light-band states while keeping the palette asymmetry distinct from Elara. Each portrait is supplied as a transparent-background holographic UI asset suited to circular panel crops.

| Variant | Visual read | Distinguishing treatment |
|---|---|---|
| `human_shadow.png` | Default opening-state register | Cold blue-grey palette, heavy silhouette, underlit eyes, strongest mechanical severity |
| `human_balanced.png` | Transitional humanization | Warmer neutrals, softer under-eye treatment, slightly reduced mechanical harshness |
| `human_warm.png` | Gift-register warmth | Amber-adjacent highlights, steadier gaze, fuller warmth without sentimental softness |

The warm-band portrait was finalized through controlled post-processing after two generative attempts introduced visual artifacts. The final result keeps the anatomy stable while moving the portrait into the required warmer emotional register.
