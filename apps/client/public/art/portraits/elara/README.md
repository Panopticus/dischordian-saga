# Elara Portrait Set Notes

The three Elara portraits share a consistent centered framing, facial identity, and holographic UI silhouette suitable for circular companion-panel crops. Each asset is delivered with a transparent background for flexible compositing.

| Variant | Visual read | Distinguishing treatment |
|---|---|---|
| `elara_lucid.png` | Default stable hologram | Clean cyan register, restrained scanline texture, balanced realism |
| `elara_fragmented.png` | Unstable damaged projection | Cyan-magenta bleed, eye desynchronization, signal tearing, heavier glitching |
| `elara_luminous.png` | Elevated integrated state | Brighter core, cleaner edges, warmer face read, more human presence |

Together, the set supports the stability-band logic described in the asset brief while preserving a premium AAA sci-fi portrait language.
