# Noire Hologram Materialize Variant

The delivered `hologram-materialize-noire` clip is a cold, palette-controlled reveal effect intended for the Human's staged materialization beat. The motion language favors restrained raster emergence, digital particle buildup, and a gradual lock-in to a stable portrait state rather than a hard pop-in.

Both `.mp4` and `.webm` variants are included to support flexible runtime integration. The clip was generated against the Human shadow-band portrait so the reveal language remains visually aligned with the companion-panel identity.
